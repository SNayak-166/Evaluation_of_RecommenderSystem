# Movie Recommendation System: Algorithm Comparison

[![Open In Colab](https://google.com)](https://google.com)

This project evaluates and compares different machine learning algorithms for a movie recommendation system using a 649 MB Kaggle dataset.

## How to Run the Evaluation

To evaluate my work and run the exact machine learning pipeline, follow these steps:

1. Click the **Open in Colab** badge at the top of this page.
2. In the Colab menu, click **Runtime** > **Run all**.
3. When prompted by the notebook, input your **Kaggle Username** and **Kaggle API Key** to dynamically stream the dataset.

*Note: If you need an API key, log into Kaggle, go to your account **Settings**, scroll to the **API** section, and click **Create New Token** to download your credentials.*
